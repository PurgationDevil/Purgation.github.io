1.1 顺序表

什么是顺序表？

通俗理解： 顺序表就像一排连续的车位，每个车位都有编号（0,1,2,3…），你可以把车（数据）停进去。

特点：

  • 车位是连续的，挨在一起的
  • 知道编号就能直接找到那个车位（比如我说”第3个车位”，你直接走过去）
  • 但是车位总数是固定的（比如最多停100辆车）

void insertElem(SeqList *L, int pos, int value) {
    // 检查1：插入位置是否有效（1到length+1之间）
    if (pos < 1 || pos > L->length + 1) {
        printf("插入位置无效！\n");
        return;
    }
    
    // 检查2：顺序表是否已满
    if (isFull(L)) {
        printf("顺序表已满，无法插入！\n");
        return;
    }
    
    // 移动元素（从后往前移）
    for (int i = L->length; i >= pos; i--) {
        L->data[i] = L->data[i - 1];
    }
    
    // 插入新元素
    L->data[pos - 1] = value;
    L->length++;
    
    printf("成功在位置%d插入元素%d\n", pos, value);
}

第1步：检查位置合法性

  • pos > L->length + 1：比如当前有5个元素，可以在第6个位置插入（末尾），但不能在第7个位置

第2步：检查是否已满

void deleteAllByValue(SeqList *L, int value) {
    int count = 0;
    int i = 0;
    while (i < L->length) {
        if (L->data[i] == value) {
            // 移动后续元素
            for (int j = i; j < L->length - 1; j++) {
                L->data[j] = L->data[j + 1];
            }
            L->length--;
            count++;
            // 注意：这里i不增加，因为新的元素移到了当前位置
        } else {
            i++;
        }
    }
    
    if (count > 0) {
        printf("成功删除%d个值为%d的元素\n", count, value);
    } else {
        printf("未找到值为%d的元素\n", value);
    }
}

1.2 单链表

什么是链表？

通俗理解： 链表就像寻宝游戏，每个宝藏（结点）都藏着一个线索（指针），告诉你下一个宝藏在哪里。宝藏可以放在任何地方（不连续的内存），通过线索串起来。

特点：

  • 不连续：每个结点可以放在内存的任何位置
  • 通过指针连接：每个结点知道下一个结点在哪
  • 动态：需要多少就创建多少，不会浪费空间

  • rear：指向队尾元素的下一个位置（空位置）
  • 队列空：front == rear
  • 队列满：(rear + 1) % MAXSIZE == front（留一个空位判断满）

为什么要留一个空位？ 如果不留空位，队列满时 front == rear 和队列空时一样，无法区分。

2.4 链表循环队列

什么是链式循环队列？

通俗理解：

  • 用链表实现的队列，队尾的 next 指向队头，形成一个圆环
  • 和顺序循环队列不同：没有”假溢出”，不需要留空位
  • 可以无限添加（只要内存够）

4.1 图

到底什么是“图”？

你想象一下地铁线路图。地铁图就是最经典、最好理解的“图结构”。

  • 每一个站点，就是一个 顶点。
  • 站点之间的铁轨，就是一条 边。

所以，图 = 顶点 + 边。

1. 无向图（Undirected Graph）

边没有箭头，关系是双向的。

就像两个人握手：

  • A 握了 B 的手，B 自然也就握了 A 的手。

2. 有向图（Directed Graph）

边有箭头，关系是单向的。

就像微博关注：

  • 你关注了某个明星，但明星不一定关注你。

简单图：

  • 没有“重复的边”。
  • 没有“自己指自己”的边。

多重图：

  • 允许两站之间有多条铁轨。
  • 允许一个站有环形地铁线（自环）。

3. 完全图（Complete Graph）

每两个顶点之间都直接连一条边。

  • 5 个同学组队，要求任意两个人都加了好友。这就是无向完全图。
图类型 边数公式 为什么？
无向完全图 n(n-1)/2 每对人一条边，除 2 是因为 A-B 和 B-A 是同一件事
有向完全图 n(n-1) 每对人要两条边：A→B 和 B→A

4. 子图（Subgraph）

在原图里删掉一些顶点或边，剩下的就是子图。

如果一个无向图里，任意两个站都能互相走到叫连通图。

4.3 最小生成树（MST）

在带权无向图中，找一个包含所有顶点的树，且所有边的权值之和最小。

通俗理解：有 n 个城市，要修路让它们都连通，且总造价最低。这就是“最小生成树”问题。

  • 包含所有顶点
  • 是树 → n 个顶点，n-1 条边，无环
  • 权值和最小

是否有唯一性：✅ 当所有权值互不相同时有唯一性。❌ 在存在权值相同的边时可能不唯一。

1. Prim 算法（加点法）

核心思想：从点出发。任选一个起点，每次找离当前树最近的顶点加入，直到所有顶点都在树中。

第一步：从 A 出发 当前树：{A} 候选边：A-B(4)、A-C(2) → 选最小的 A-C(2)，加入 C

第二步：当前树 {A, C}，树外 {B, D} 候选边：

  • A-B(4)
  • C-B(5)
  • C-D(8) 最小值是 A-B(4) → 加入 B

第三步：当前树 {A, B, C}，树外 {D} 候选边：

  • B-D(1)
  • C-D(8) 最小值是 B-D(1) → 加入 D

4.4 最短路径（Shortest Path）

在带权图中，找两个顶点之间权值之和最小的路径。

最短路径的两种经典问题

问题类型 说明 算法
单源最短路径 从一个起点到所有其他点的最短路径 Dijkstra、Bellman-Ford

1. Dijkstra 算法（单源，权值非负）

核心思想：贪心。从起点出发，每次找离起点最近的顶点，用它去更新其他顶点的距离。

规则：

1. dist[i]：起点到 i 的当前最短距离（初始：起点=0，其他=∞）。 2. 从未确定的顶点中选 dist 最小的顶点 u，标记 u 为“已确定”。 3. 用 u 更新它的邻居：dist[v] = min(dist[v], dist[u] + w(u,v))。 4. 重复 2-3，直到所有顶点都确定。

    B -- 5 --> C
    B -- 1 --> D
    C -- 8 --> D

第1步：选 A（dist 最小=0），标记 A 已确定。 更新邻居：

  • dist[B] = min(∞, 0+4) = 4
  • dist[C] = min(∞, 0+2) = 2

当前 dist：A✅, B(4), C(2), D(∞)

第2步：未确定中最小的 C（2），标记 C 已确定。 更新邻居（C 到 D 有边 8）：

  • dist[D] = min(∞, 2+8) = 10

因为贪心假设：当前选的最小 dist 不会再被更新。负权边可能让一个已经确定的路由变得更短 → 算法失效。

2. Floyd 算法（多源，可负权，无负环）

核心思想：动态规划。逐个顶点作为“中间点”，看能不能让两点之间的距离变短。

压缩后：dist[i][j] 直接更新。

void floyd(int n, int dist[MAX][MAX]) {
    for (int k = 0; k < n; k++) {			// 中间点
        for (int i = 0; i < n; i++) {		// 起点
            for (int j = 0; j < n; j++) {	// 终点
                if (dist[i][k] + dist[k][j] < dist[i][j]) {
                    dist[i][j] = dist[i][k] + dist[k][j];
                }
            }
        }
    }
}

4. 常见问题

1. Dijkstra 为什么用优先队列（堆）优化？

普通写法每次找最小值 O(n)，用堆可以降到 O(log n)，总复杂度 O(m log n)。

2. Dijkstra 能处理有环图吗？

能。它只是不能处理负权边，有正权环没问题。

3. 负权环怎么办？

Floyd 和 Bellman-Ford 可以检测负权环。负权环存在时，最短路径无解（可以无限小）。

4.5 拓扑排序（Topological Sort）

定义：对一个有向无环图（DAG） 的所有顶点进行线性排序，使得对于每条边 u → v，u 都排在 v 的前面。（任务 A 完成后才能做 B）

graph LR
    1 --> 2
    1 --> 3
    2 --> 4
    3 --> 4

拓扑排序：1 → 2 → 3 → 4 或 1 → 3 → 2 → 4

方法一：Kahn 算法（BFS（广度优先） / 贪心）

核心思想：不断找入度为 0 的顶点，删掉它和它的出边。

代码思路：

1. 统计所有顶点的入度。 2. 把所有入度为 0 的顶点入队。 3. 取出队首顶点 u，输出。 4. 对于 u 的每个邻居 v，把 v 的入度减 1。 5. 如果 v 的入度变成 0，把 v 入队。 6. 重复 3-5，直到队列为空。

  • 入度为 0 的顶点：{2, 3} → 输出 2，删掉 2 的出边（2→4） 更新入度：4(2→1)

#include <stdio.h>
#include <stdlib.h>

#define MAX 100

// 邻接表结点
typedef struct ArcNode {
    int adjvex;
    struct ArcNode* next;
} ArcNode;

// 顶点结点
typedef struct VNode {
    int data;
    ArcNode* first;
} VNode, AdjList[MAX];

typedef struct {
    AdjList vertices;
    int vexnum, arcnum;
} ALGraph;

// 简单队列
typedef struct {
    int data[MAX];
    int front, rear;
} Queue;

void initQueue(Queue* q) {
    q->front = q->rear = 0;
}

int isEmpty(Queue* q) {
    return q->front == q->rear;
}

void enqueue(Queue* q, int v) {
    q->data[q->rear++] = v;
}

int dequeue(Queue* q) {
    return q->data[q->front++];
}

// 拓扑排序（Kahn算法）
int topologicalSort(ALGraph* G, int result[]) {
    int indegree[MAX] = {0};
    Queue q;
    initQueue(&q);
    int count = 0;  // 已输出的顶点数

    // 1. 统计入度
    for (int i = 0; i < G->vexnum; i++) {
        ArcNode* p = G->vertices[i].first;
        while (p != NULL) {
            indegree[p->adjvex]++;
            p = p->next;
        }
    }

    // 2. 入度为0的顶点入队
    for (int i = 0; i < G->vexnum; i++) {
        if (indegree[i] == 0) {
            enqueue(&q, i);
        }
    }

    // 3. 处理队列
    while (!isEmpty(&q)) {
        int u = dequeue(&q);
        result[count++] = u;

        ArcNode* p = G->vertices[u].first;
        while (p != NULL) {
            int v = p->adjvex;
            indegree[v]--;
            if (indegree[v] == 0) {
                enqueue(&q, v);
            }
            p = p->next;
        }
    }

    // 4. 判断是否有环
    if (count != G->vexnum) {
        printf("图中有环，无法拓扑排序！\n");
        return 0;
    }
    return 1;
}

方法二：DFS 方法（深度优先）

核心思想：用 DFS 遍历，在回溯时把顶点加入结果栈，最后反转。

步骤：

1. 对每个未访问的顶点调用 DFS。 2. 在 DFS 中，先递归访问所有邻居。 3. 回溯时把当前顶点压入栈。 4. 最后栈顶到栈底就是拓扑排序‘。

4.6 关键路径（Critical Path）
